# Склад

## Склады

`Склад → Склады` — заведите хотя бы один склад до того, как начнёте
проводить любые документы, влияющие на остатки. Остатки в системе всегда
привязаны к конкретному складу, «общего» остатка без склада не бывает.

## Виды складских движений

Каждое изменение остатка — отдельная запись-документ определённого вида:

| Движение | Что делает |
|---|---|
| Оприходование | Добавляет остаток вручную (без привязки к заказу поставщику) |
| Списание | Уменьшает остаток вручную (порча, недостача) |
| Перемещение | Переносит остаток с одного склада на другой |
| Инвентаризация | Корректирует остаток до фактически пересчитанного количества |
| Отгрузка | Списывает остаток при отгрузке по заказу покупателя |
| Приёмка | Добавляет остаток при приёмке по заказу поставщику |
| Возврат от клиента | Возвращает остаток при возврате по заказу |
| Возврат поставщику | Списывает остаток при возврате поставщику |
| Расход в производство | Списывает сырьё при запуске производственного задания |
| Выпуск продукции | Добавляет остаток готовой продукции по завершении производства |
| Розничная продажа / Розничный возврат | То же самое, но через кассу — см. [Розница](06-retail.md) |

Создать движение вручную (Оприходование/Списание/Перемещение/
Инвентаризация) — `Склад → Движения → Новое движение`. Остальные виды
создаются автоматически из соответствующих документов (заказ, приёмка,
касса, производство) — отдельно их вручную заводить не нужно.

## Черновик и проведение

Некоторые движения (например, Отгрузка через «Создать документ» на заказе)
сначала создаются как **черновик** — можно скорректировать склад/количества
на его собственной странице. Остаток фактически меняется только после
**проведения** — это осознанная защита от случайного искажения остатков
незавершённым документом.

## Остатки

`Склад → Остатки` — текущий остаток по каждому товару на каждом складе, с
учётом резерва (сколько зарезервировано под заказы и сколько реально
доступно к продаже). Здесь же:

- **Дефицит** — товары, у которых задан минимальный остаток
  (в карточке товара) и фактический остаток по всем складам суммарно упал
  ниже него;
- **Партии со сроком годности** — если при приёмке указывался срок годности
  партии, здесь видно, что и когда истекает;
- **Комплекты** — сколько комплектов можно собрать прямо сейчас исходя из
  остатков компонентов.

## Партионный учёт себестоимости

Себестоимость проданного товара считается не «средней ценой», а по
конкретной партии закупки, из которой физически списан товар (первой из
поступивших — «первый пришёл, первый ушёл»). Это отражается в отчёте
[«Прибыли и убытки»](08-finance-and-reports.md), а не где-то в карточке
товара напрямую.
