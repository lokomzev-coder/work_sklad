# Производство

## Техкарты

`Производство → Техкарты` — рецепт изготовления: какая готовая продукция
получается, из какого сырья (список компонентов с количеством на единицу
выпуска), и, при необходимости, затраты труда/накладные расходы. Техкарту
нужно завести один раз для каждого производимого товара до того, как
создавать по нему производственные задания.

## Техпроцессы (многоэтапное производство)

Если изготовление товара проходит несколько последовательных этапов
(например, «Раскрой» → «Сборка» → «Покраска») — заведите техпроцесс
(`Производство → Техпроцессы`) с нужными этапами. Каждый этап может списывать
своё сырьё и передавать полуфабрикат на следующий этап. Для простого
одноэтапного изготовления техпроцесс не обязателен — достаточно обычной
техкарты.

## Производственное задание

`Производство → Новое задание` — выберите техкарту (или техпроцесс) и
количество к выпуску. При запуске задания списывается сырьё согласно
техкарте (движение «Расход в производство»), при завершении — приходуется
готовая продукция (движение «Выпуск продукции»). Если производство
многоэтапное, задание переходит по этапам последовательно — прогресс виден
на карточке задания.

## Интерфейс цеха

Сотрудник с ролью **PRODUCTION** видит не обычный дашборд, а упрощённый
интерфейс `/floor` — только те производственные задания и этапы, которые
относятся к нему, без доступа к остальной системе (заказам, финансам и
т.п.).
