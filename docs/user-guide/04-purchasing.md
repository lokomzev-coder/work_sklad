# Снабжение

## Заказы поставщику

`Заказы поставщику → Новый заказ`. Выберите поставщика (заводится в том же
справочнике «Клиенты» — контрагент может быть одновременно и покупателем, и
поставщиком), добавьте позиции, укажите склад для будущей приёмки.

Как и у заказа покупателя, у заказа поставщику настраиваемый статус и
собственный бизнес-процесс переходов (`Заказы поставщику →
Бизнес-процессы`).

## Приёмка товара

На карточке заказа поставщику — панель «Приёмка»: укажите, сколько из
заказанного количества фактически поступило (может быть частями, в
несколько приёмок), при желании — партию и срок годности для конкретной
поступившей партии. Приёмка создаёт складское движение и увеличивает
остаток на выбранном складе; себестоимость для последующих продаж
считается по фактической цене именно этой партии (партионный учёт,
списание по принципу «первый пришёл — первый ушёл»).

## Счета поставщиков

`Счета поставщиков` — входящие счета от поставщиков, можно создать из
заказа поставщику или отдельно. Оплата по счёту фиксируется как обычный
платёж (`Платежи`, направление «Исходящий»).

## Возврат поставщику

С карточки заказа поставщику можно оформить возврат части или всех
поступивших товаров — создаёт обратное складское движение и уменьшает
остаток.
