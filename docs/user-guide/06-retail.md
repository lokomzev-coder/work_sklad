# Розница (касса)

Отдельный интерфейс, не обычный дашборд — открывается по адресу `/kassa`
вашей организации. Сотрудник с ролью **CASHIER** видит только его; ADMIN
может заходить и туда, и в обычный интерфейс.

## Открытие смены

Перед первой продажей нужно открыть кассовую смену — `Открыть смену`,
указать склад, с которого будут продаваться товары. Пока смена не открыта,
продажи оформить нельзя. В конце дня смену нужно закрыть — после закрытия
новые продажи в неё уже не добавить.

## Продажа

На главном экране кассы — поиск товара (по названию, артикулу или
сканированием штрихкода), добавление позиций в чек, выбор способа оплаты
(наличные/карта), клиент — не обязателен (можно продать без привязки к
конкретному клиенту, «розничный покупатель»). При завершении продажи
остаток товара списывается со склада смены сразу же.

## Фискальный чек

Если для организации настроена фискализация (интеграция с онлайн-кассой —
настраивается администратором отдельно, не в кассовом интерфейсе), при
завершении продажи автоматически формируется и отправляется фискальный
чек с корректной ставкой НДС по каждой позиции (берётся из карточки
товара). Если фискализация не настроена, продажа всё равно проводится и
списывает остаток — просто без фискального чека.

## Возврат

`Возврат` — оформляется по номеру предыдущей продажи (не обязательно из
этой же смены), можно вернуть часть или все позиции. Возврат добавляет
остаток обратно на склад.

## Профиль кассира

Кассир видит свой профиль и историю своих продаж за текущую смену через
`Профиль` в кассовом интерфейсе.
