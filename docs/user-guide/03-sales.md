# Продажи

## Клиенты

`Клиенты` — карточка клиента: реквизиты, ИНН, контакты. На карточке клиента
видна вся история заказов и текущий баланс взаиморасчётов (сколько клиент
должен вам и сколько вы должны ему, если он одновременно и покупатель, и
поставщик).

## Заказы покупателей

`Заказы → Новый заказ`. Выберите клиента, добавьте позиции из каталога,
укажите склад (с которого будет отгрузка), при необходимости — канал
продаж, договор, ответственного сотрудника, проект.

У заказа несколько **независимых** характеристик состояния — это не одно и
то же:

- **Статус** — настраиваемый (см. ниже), показывает, на каком этапе
  находится заказ («Новый», «В работе», «Выполнен» и т.п. — конкретные
  статусы и переходы между ними задаёт администратор).
- **Проведено** (чекбокс в шапке заказа) — влияет на резерв и остатки;
  включено по умолчанию даже у нового заказа.
- **Резерв** (чекбокс) — резервирует товар под этот заказ на складе, чтобы
  его нельзя было случайно продать по другому заказу; требует, чтобы заказ
  был проведён и был указан склад.
- **Оплата** — бейдж «Не оплачено» / «Частично» / «Оплачено», считается
  автоматически по внесённым платежам, вручную не проставляется.

## Статусы и кто что может

Список статусов и переходы между ними для каждого типа документа настраивает
администратор — `Заказы → Бизнес-процессы` (или соответствующий пункт для
Заказов поставщику). Там же задаётся, **кто именно** может создать документ
в каком статусе и кто может выполнить каждый конкретный переход — по
конкретным сотрудникам, отделам или ролям. Если в выпадающем списке статуса
не видно нужного значения — скорее всего, вашей роли/отделу/вам лично не
разрешён этот переход, а не техническая ошибка.

## «Создать документ»

Кнопка на карточке заказа — превращает заказ в следующий документ по
цепочке, перенося позиции и суммы:

- **Отгрузка** — создаёт черновик складского движения (можно ещё
  скорректировать склад/количества на его собственной странице), при
  проведении списывает товар со склада;
- **Счёт покупателю** — создаёт печатный счёт на основе заказа.

## Счета покупателям

`Счета покупателям` — список всех выставленных счетов, отдельно от заказов
(счёт можно создать и не через заказ). На счёте — печатная форма, статус,
привязанные платежи.

## Платежи

`Платежи` — все входящие и исходящие платежи по заказам, счетам, заказам
поставщику. Платёж привязывается к конкретному документу и валюте; для
операций без привязки к заказу/счёту (взнос учредителя, хозрасходы) —
смотрите «Кассовые ордера» в [Настройках и автоматизации](09-settings-and-automation.md).

## Задачи и комментарии

На карточке любого документа — вкладка с обсуждением (комментарии видят
все, у кого есть доступ к самому документу) и, отдельно, `Задачи` в главном
меню — можно поставить задачу сотруднику и, при желании, привязать её к
конкретному документу.

## Файлы на документе

В самом низу карточки документа — секция «Файлы»: можно приложить скан,
договор, любой другой файл, относящийся к этому конкретному заказу/счёту.
