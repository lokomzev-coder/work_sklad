# Первые шаги

## Регистрация и вход

При первой регистрации вы создаёте и учётную запись пользователя, и
организацию одновременно — форма регистрации спрашивает и ваши данные, и
название компании. Вход дальше — по логину и паролю. Если вы состоите
больше чем в одной организации (например, вас пригласили в чужую компанию),
после входа система попросит выбрать, с какой организацией работать сейчас
— переключиться на другую можно в любой момент через меню профиля.

## Роли сотрудников

У каждого сотрудника есть одна из базовых ролей:

| Роль | Кому подходит |
|---|---|
| **ADMIN** | Владелец/администратор — полный доступ ко всему, включая настройки и права других сотрудников |
| **MANAGER** | Руководитель отдела — доступ ко всем рабочим разделам, но не к самым чувствительным настройкам (API-ключи, журнал изменений и т.п. настраиваются отдельно) |
| **EMPLOYEE** | Рядовой сотрудник — доступ по умолчанию к основным рабочим разделам, без настроек |
| **CASHIER** | Кассир — видит только кассовый интерфейс (`/kassa`), не обычный дашборд |
| **PRODUCTION** | Сотрудник производства — видит только интерфейс производственного цеха (`/floor`), не обычный дашборд |

Если стандартных ролей недостаточно (например, нужно дать конкретному
сотруднику доступ только к заказам и складу, без клиентов и финансов) —
администратор может создать **кастомную роль** с точной настройкой прав по
каждому разделу: `Настройки → Роли доступа`. Подробнее — в разделе
[Настройки и автоматизация](09-settings-and-automation.md).

## Приглашение сотрудников

`Сотрудники → Добавить сотрудника`. У сотрудника можно сразу задать:

- ФИО, должность, контакты;
- роль (базовую или кастомную);
- отдел (`Настройки → Отделы`) — используется для прав «видеть только
  документы своего отдела»;
- склад по умолчанию — предзаполняет выбор склада на новых документах,
  не ограничивает доступ;
- юридическое лицо по умолчанию — то же самое для юрлица.

Сотрудник и учётная запись для входа — разные вещи: можно завести
сотрудника в справочнике без права входа в систему (например, для отчётов),
а можно привязать к нему логин, чтобы он сам заходил и работал.

## Личный кабинет

Каждый сотрудник со своим логином может зайти в `Профиль` и поменять своё
имя, email, пароль — без обращения к администратору.

## Организация: юридические лица

`Настройки → Юрлица` — карточка вашей компании (или нескольких, если вы
ведёте документы от имени разных юрлиц): название, ИНН/КПП/ОГРН,
банковские реквизиты. Одно юрлицо можно пометить «по умолчанию» — оно будет
предзаполняться на новых документах.
