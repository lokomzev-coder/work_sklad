# Руководство пользователя EasyWork

Эти материалы — для сотрудника организации, которая работает в сервисе, а
не для разработчика. Если вы ищете техническую документацию (API,
деплой, интеграции) — она в `docs/handbook/`, это другой раздел для другой
аудитории.

## Быстрый чек-лист для новой организации

Минимальный набор действий, чтобы начать реально работать в системе:

- [ ] Заполните реквизиты своей организации (юрлицо) —
      `Настройки → Юрлица`.
- [ ] Добавьте хотя бы один склад — `Склад → Склады`.
- [ ] Заведите первые товары/услуги — `Товары и услуги`.
- [ ] Пригласите сотрудников и назначьте им роли —
      `Сотрудники`.
- [ ] Если планируете розничные продажи — настройте кассовую смену и
      (при необходимости) фискализацию — см. [Розница](06-retail.md).
- [ ] Заведите первого клиента и создайте тестовый заказ, чтобы убедиться,
      что весь путь «заказ → отгрузка → оплата» настроен так, как нужно
      именно вашей компании — см. [Продажи](03-sales.md).

## Роли и права коротко

У сотрудника есть базовая роль (**ADMIN**, **MANAGER**, **EMPLOYEE**), а
администратор может дополнительно создать **кастомные роли** с точной
настройкой прав по каждому разделу (`Настройки → Роли доступа`) — подробнее
в [Настройках и автоматизации](09-settings-and-automation.md). Если
какого-то пункта меню не видно — скорее всего, дело в правах, а не в
ошибке; проверьте роль сотрудника или обратитесь к администратору
организации.
