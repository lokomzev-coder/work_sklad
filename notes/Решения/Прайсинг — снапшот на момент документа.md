# Прайсинг — снапшот на момент документа

Встречается во всех строчных таблицах документов: `OrderLineItem.unitPriceSnapshot`, `PurchaseOrderLineItem.unitPriceSnapshot`, `StockMovementLine.unitPriceSnapshot` (для DEMAND/SUPPLY).

## Правило

Цена/себестоимость **фиксируется в момент создания документа** и больше никогда не меняется автоматически, даже если позже поменяется цена в [[Каталог|каталоге]]. Уже созданный заказ/движение — исторический факт, не живая ссылка на текущую цену.

## Откуда берётся снапшот

- `Order` → снимается из `CatalogItem.unitPrice`, либо из `CatalogItemVariant.priceOverride`, если выбрана модификация (см. [[Каталог#Модификации (Variant)]]) — **не редактируется пользователем вручную**
- `PurchaseOrder` → вводится пользователем вручную (закупочная цена у разных поставщиков разная — автоматика тут была бы неверной), автоподстановка текущей цены каталога — только начальное значение поля, не жёсткая привязка
- `DEMAND`/`SALES_RETURN` → берётся из `OrderLineItem.unitPriceSnapshot` того же заказа (не из каталога повторно) — иначе отгрузка могла бы "уехать" по цене от того, что было согласовано в заказе
- `SUPPLY`/`PURCHASE_RETURN` → аналогично, из `PurchaseOrderLineItem.unitPriceSnapshot`

## Почему это важно

Без этого правила изменение цены товара в каталоге задним числом переписало бы сумму уже оплаченных/закрытых заказов — [[Отчёты|P&L и балансы]] считали бы неверные исторические цифры.
