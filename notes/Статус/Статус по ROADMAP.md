# Статус по ROADMAP

Снимок на момент создания этой заметки. Полная версия с обоснованием каждого пункта — файл `ROADMAP.md` в корне репозитория (не дублируется здесь построчно, только сводка + ссылки на домены).

## Готово

- MVP целиком (авторизация, роли, сотрудники, клиенты, [[Пароли (vault)]], полировка UI)
- [[Каталог]] — кроме отдельного остатка по модификациям
- [[Склад]] — целиком (склады, остатки, 8 типов движения)
- [[Заказы и закупки]] — целиком, включая возвраты
- [[Контрагенты]] — кроме нескольких юрлиц компании и нескольких адресов клиента
- [[Отчёты]] — первый набор (обороты, деньги, P&L, продажи по клиентам)

## Сознательно не реализовано

- Настраиваемые статусы документов (C4) — отдельный workflow-движок, не начато
- Несколько юрлиц компании (D1) — не нужно почти никому из целевой аудитории
- Блок E (розница) и F (производство) — ROADMAP прямо запрещает начинать без явного запроса
- Блок H целиком (печатные формы/PDF, реальная мультивалютность с конвертацией, пользовательские поля, вебхуки) — каждое отдельная крупная подсистема, "по ходу", не заранее

Если возвращаетесь к проекту после паузы — начните с [[Home]], потом [[Стек и структура]] (операционные особенности локальной среды), потом домен, с которым будете работать.
