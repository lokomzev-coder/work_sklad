# Глоссарий МойСклад

Соответствие терминов МойСклад ↔ наша модель. Не копируем API 1:1, переносим смысл в свой стиль — таксономия взята из `github.com/moysklad/api-remap-1.2-doc`.

| МойСклад | У нас | Заметка |
|---|---|---|
| `product` / `service` / `bundle` | `CatalogItem.type` | одна таблица с discriminator, см. [[Каталог]] |
| `variant` | `CatalogItemVariant` | без отдельного остатка (упрощение) |
| `characteristic` | `Characteristic` | справочник |
| `productFolder` | `CatalogGroup` | дерево |
| `uom` | `Unit` | справочник |
| `store` | `Store` | см. [[Склад]] |
| `enter`/`loss`/`move`/`inventory` | `StockMovementType` | те же 4 + ещё 4 бизнес-типа |
| `customerOrder` | `Order` | не переименовывали |
| `demand` | `StockMovement.type = DEMAND` | не отдельная модель, см. [[Леджер вместо отдельных документов]] |
| `salesReturn` | `StockMovement.type = SALES_RETURN` | |
| `purchaseOrder` | `PurchaseOrder` | |
| `supply` | `StockMovement.type = SUPPLY` | |
| `purchaseReturn` | `StockMovement.type = PURCHASE_RETURN` | |
| `counterparty` | `Client` | одна модель для покупателя и поставщика, см. [[Контрагенты]] |
| `contract` | `Contract` | минимально, не документооборот |
| `saleschannel` | `SalesChannel` | |
| `paymentIn`/`paymentOut` | `Payment.direction` | без полноценных `invoice` |
| `organization` (юрлицо компании) | — | не реализовано (D1) |
| `report_stock` | `/warehouse/stock` | |
| `report_turnover` | `/reports/turnover` | |
| `report_money` | `/reports/money` | |
| `report_pnl` | `/reports/pnl` | упрощённый расчёт |
| `retaildemand`, кассы | — | Блок E, не начато |
| `processingplan` (производство) | — | Блок F, не начато |

См. [[Статус по ROADMAP]] для актуального статуса каждого блока.
