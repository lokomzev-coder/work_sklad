# Стек и структура

Next.js 16 (App Router, Turbopack) + Prisma 7 + PostgreSQL (`prisma dev` локально) + shadcn/ui на базе **Base UI** (не Radix!) + Tailwind v4. Палитра — изумрудная (OKLCH).

Важно: Next.js 16 и Prisma 7 — мажорные версии с breaking changes относительно обучающих данных модели. См. `node_modules/next/dist/docs/` и `AGENTS.md` в корне репозитория перед правками.

## Слои

- `src/app/(dashboard)/[org]/**` — страницы, серверные компоненты, читают через `prisma` напрямую
- `src/actions/*.ts` — Server Actions (`"use server"`), единственная точка мутаций, каждый сам проверяет [[Ролевая модель|права]] и `orgId`
- `src/components/**` — клиентские компоненты форм/виджетов
- `src/lib/*.ts` — общая бизнес-логика без UI (`tenant.ts`, `permissions.ts`, `archive.ts`, `stock.ts`, `balances.ts`, `reports.ts`, `crypto.ts`)
- `prisma/schema.prisma` — единственный источник истины по данным

## Особенности Prisma 7

- Конфиг подключения — `prisma.config.ts`, не в `schema.prisma`
- Генератор `prisma-client` (ESM) → `src/generated/prisma`
- Обязателен driver adapter (`@prisma/adapter-pg` + `pg`) для PostgreSQL
- `package.json` — `"type": "module"`

## Особенности Base UI (не Radix!)

- `asChild` не существует — вместо этого проп `render={<Link .../>}`
- `<Select.Value>` **не** сопоставляет value→label сам — нужен проп `items` на `Select.Root`, иначе видно сырое значение (см. [[Select показывает сырое значение]])
- Наш `Button` сам выставляет `nativeButton={false}`, если передан `render` (иначе предупреждение о доступности)

## Локальная БД — известная особенность

`npx prisma dev` (инстанс `easywork-dev`, база `easywork`, НЕ `template1`) может самопроизвольно останавливаться. Симптом: 500-е ошибки, `ConnectionClosed`/`ECONNRESET`. Лечится: `npx prisma dev stop easywork-dev && npx prisma dev start easywork-dev`, затем перезапустить `npm run dev` (старый пул соединений не переживает падение БД).

Схему менять через `npx prisma db push` (не `migrate dev` — упирается в баг с shadow-базой), затем `npx prisma generate`, затем **обязательно** перезапустить dev-сервер (иначе `Cannot read properties of undefined` на новой модели — старый долгоживущий процесс держит устаревший клиент).
