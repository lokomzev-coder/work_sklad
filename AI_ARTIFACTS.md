# AI-инструментарий: что убрать перед деплоем

Список файлов и папок в этом репозитории, которые существуют только для работы
со мной (Claude Code) и другими AI-агентами — не часть продукта. Веду и
обновляю этот список по ходу разработки; сверяйтесь с ним перед подготовкой
деплой-сборки/публичного репозитория.

## Безопасно удалить целиком

| Путь | Что это | Почему не нужно в проде |
|---|---|---|
| `AGENTS.md` | Инструкции для AI-агентов про особенности этой версии Next.js | Только для агента, не для рантайма |
| `CLAUDE.md` | Точка входа инструкций для Claude Code (просто `@AGENTS.md`) | Аналогично |
| `.claude/` | Настройки Claude Code и claude-flow: `settings.json`/`settings.local.json`, `agents/` (типы саб-агентов), `commands/` (slash-команды), `skills/` (кэш скиллов, включая `agentdb-*`, `v3-*`, `swarm-*` и т.д.), `helpers/` (shell/mjs-скрипты хуков), `proven-config.json`, `.proven-config-version`, `scheduled_tasks.lock` | Инструмент разработки, не продукт |
| `.claude-flow/` | Состояние оркестратора claude-flow: `config.yaml`, `CAPABILITIES.md`, `daemon-state.json`, `daemon.pid`, `harness-active-policy.json`, `memory-package.json`, `metrics/*.json`, `policy/state.json`, `security/audit-status.json` | Рантайм-состояние AI-инструмента, полностью эфемерно |
| `.swarm/` | БД памяти роя агентов: `memory.db`, `schema.sql`, `backups/` | Локальная память claude-flow между сессиями, не продукт |
| `.agents/` | Реальное содержимое AI-скиллов (Prisma-документация для агентов), на которое ссылаются симлинки в `.claude/` и `.windsurf/` | Аналогично |
| `.windsurf/` | Симлинки скиллов для Windsurf (тот же контент, что в `.agents/`) | Аналогично |
| `skills-lock.json` | Манифест версий AI-скиллов, которые подтянула Prisma-тулза | Аналогично |
| `chat_history.md` | Хронологическая история этой сессии разработки с Claude Code (192 КБ и растёт) | Рабочий журнал, не документация продукта |
| `notes/` | Obsidian-vault с картой связей проекта (заметки для навигации ИИ между сессиями) — включает `.obsidian/` (настройки самого Obsidian) | Вспомогательный граф для ИИ, не продуктовая документация |
| `.playwright-mcp/` | Скриншоты/логи консоли от браузерного MCP-инструмента (старый, MCP-режим) | Уже в `.gitignore`, эфемерно — просто предупреждение, если где-то осталось |
| `.playwright-cli/` | Скриншоты/консоль-логи/page-снапшоты от `@playwright/cli` (текущий инструмент для проверки UI) | Эфемерные артефакты прогонов, не часть продукта |
| `tmp-*.mts`, `tmp-*.ts` в корне | Одноразовые скрипты проверки (создаю и удаляю сам после прогона) | Если где-то остался — значит забыл удалить, можно смело удалять |

## Требует решения, не только техническое (не удалять не глядя)

| Путь | Что это | На что обратить внимание |
|---|---|---|
| `ROADMAP.md` | Живой план развития — написан мной, но описывает реальные архитектурные решения продукта (почему леджер вместо документов, почему `SetNull` vs `Restrict` и т.д.) | Может быть ценен как внутренняя техдокументация команды даже без контекста ИИ — решать вам: удалить целиком, оставить как есть, или почистить от AI-специфичных формулировок |

## Не требует внимания

`.env*`, `/src/generated/prisma`, `/.next/`, `node_modules` и всё остальное в
`.gitignore` — не имеет отношения к ИИ-инструментарию, обычный список
`.gitignore` для Next.js/Prisma-проекта.

## Как поддерживается этот файл

Обновляю вручную при появлении новых AI-специфичных файлов (например, если
подключится ещё один MCP-инструмент со своей конфигурацией). Если сомневаетесь,
актуален ли список — спросите, сверю с `git status`/`git ls-files`.
